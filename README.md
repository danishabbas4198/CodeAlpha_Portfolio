# CodeAlpha_Portfolio

A responsive portfolio website for Sheen Digital Agency, built with HTML, CSS and JavaScript as part of my CodeAlpha Frontend Development internship (Task 3).

## Features
- Sections for Hero, About, Services, Team, Work and Contact
- Filterable project grid (Video, Web, Bookkeeping, Ecommerce)
- Smooth scroll, scroll-reveal animations and hover effects
- Mobile menu and fully responsive layout
- Contact form with validation that opens a pre-filled Gmail draft

Open `index.html` in any browser.
